# 🛠️ Insta Tools

> **A modern Android toolkit for Instagram flags, mapping files, and JSON data.**

Insta Tools brings essential analysis and JSON utilities into one clean, lightweight Android application — built for developers, modders, and enthusiasts who work with structured data.

---

## ✨ Features

### 🚩 Flag Analysis

Analyze and inspect Instagram flags to better understand their values and structure.

### 🗂️ Mapping File Analysis

Work with mapping files and inspect their data in a more convenient way.

### 🧩 JSON Toolkit

| Tool | Description |
|---|---|
| 👁️ **JSON Viewer** | View JSON files in a clean, readable format |
| 🛠️ **JSON Maker** | Create JSON files easily |
| 🔗 **JSON Merger** | Merge multiple JSON files into one |
| ⚖️ **JSON Compare** | Compare two JSON files and find differences |
| ✅ **JSON Validator** | Check whether JSON files are valid |
| 🔎 **JSON Search** | Quickly search for flags, keys, and values |

### 🎨 Modern Interface

A clean, simple, and easy-to-use interface designed to keep powerful tools accessible without unnecessary complexity.
